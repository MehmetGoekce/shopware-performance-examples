 # Versions-Parameter an (?1790…), das CSS nicht – deshalb wird er
 # abgeschnitten.
 #
 # Nur die eine Datei vorladen, die fuer lateinischen Text gebraucht wird.
 # Wer eine eigene Schrift einbindet, setzt hier deren Pfad ein.
